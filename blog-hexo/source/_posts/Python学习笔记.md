## 三.Python的基础语法

### 1.**Python的标识符**

- 第一个字符必须是字母表中字母或下划线
- 标识符的其他的部分由字母、数字和下划线组成
- 标识符对大小写敏感

### 2.**Python的关键字**

- 关键词：保留字，我们不能用它来做任何表示符名称
- Python的关键字：如下

```
True，False，None，and，as，asset ，def ，class ，continue ，break ，else ，finally ，elif ，del ，except ，global ，for ，if ，from ，import ，raise ，try ，or ，return ，pass ，nonlocal ，in ，not ，is ，lambda
```

### 3.**Python的注释**

- 注释：编译器不执行此语句
- 单行注释：用 # 来表示

```
#print("此处是单行注释")
```

-   多行注释：用 ' 或者 " 来表示

```
'print("此处是多行注释")' 
"print("此处也是多行注释")"
```

###  4.**Python的缩进**

-   Python的缩进与其他编程语言不同，它是强制性的，必须通过Tab来与语句对齐,否则会报错!

## 四.Python的基本数据类型

### 1.**Python中的数据类型**

- 整型：整数
- 字符型：字符串
- 浮点型：小数
- 列表：\[\], list()
- 元组：(), tuple()
- 集合：set()
- 字典：{}, dict()

### 2. **每个数据类型之间能相互转换**

- int(x)--->x转为整型
- str(x)--->x转为字符型
- float(x)--->x转为浮点型
- list(x)--->x转为列表
- tuple(x)--->x转为元组
- set(x)--->x转为集合
- dict(x)--->x转为字典

_注意：有的转换必须符合转换的要求！不想这么转就怎么转_

## 七.列表

### 1.**列表的创建**

```
a = list()   #两种方法都可以
a = []
```

### 2.**列表的操作**

- 访问

```
a[0]    #代表列表a的下标为1的元素
```

- 增加

```
a.append(x)   #x代表增加的元素
```

- 删除

```
del a[x]   #x代表元素下标的索引
```

- 更新

```
a[5] = 6   #把下标索引为5的元素改为整数6
```

- 列表的长度

```
len(a)
```

- 列表的最大值

```
max(a)
```

- 列表的最小值

```
min(a)
```

- 某元素出现的次数

```
a.count(x) #x为某一元素
```

- 列表排序

```
a.sort(key=None,reverse=False)   #对列表从小到大排序,reverse=True为降序
```

- 列表反转

```
a.reverse()  #反向列表中元素
```

- 清空列表

```
a.clear()
```

- 复制列表

```
a.copy()
```

- 取出第i位并删除

```
a.pop(i)
```

- 在列表第i位插入x

```
a.insert(i,x)
```

- 将列表出现的第一个元素x删除

```
a.remove(x)
```

- 将列表b添加到列表a中

```
a.extend(b)
```

## 八.元组

### **1.元组的创建**

```
a = tuple()
a = ()
```

### 2.**元组的操作**

- 访问

```
a[0]   #代表元组a的下标为1的元素
```

- 增加：元组无法实现a\[1\] = 5增加操作，**元组的元素值是不能修改的**

- 删除

```
del a[x] #x代表元素下标的索引
```

- 修改：元组修改可以通过两个元组拼接来实现，元组的元素值是不能修改的

- 元组的个数

```
len(a)
```

- 元组的最大值

```
max(a)
```

- 元组的最小值

```
min(a)
```

**_注意：元组的元素值是不能修改的_**

## 九.集合

### 1.**集合的创建**

```
a = set()
```

### 2.**集合的操作**

- 访问：集合无法访问单独元素
- 增加

```
a.add(x) 或者 a.update(x)   #x为增加的元素
```

- 删除

```
a.remove(x)
a.discard(x)
a.pop()     
#x代表移除的元素，第二种若元素不存在会出错，所以建议使用第一种方法,第三种为随机删除
```

- 修改：集合修改可以通过两个集合 &|^+- 来实现
- 集合的个数

```
len(a)
```

- 复制集合

```
a.copy()
```

- 判断元素x是否在集合存在

```
x in s   #为存在返回True,否则False
```

- 清空集合

```
a.clear()
```

## 十.字典

### 1.**字典的组成：a = {'键':值}，由一个个键值对组成**

### 2.**字典的创建**

```
a = dict()
a = {}
```

### 3.**字典的操作**

- 读取

```
a['x']   #x代表读取元素的键，返回其值
```

- 增加

```
a['x'] = y   #x代表增加的元素的键，y代表增加元素的值
```

- 删除

```
del a['x']   #x代表删除元素的键
```

- 修改

```
a['x'] = y   #把x的值修改成y
```

- 字典的长度

```
len(a)
```

- 清空字典

```
a.clear()
```

- 复制字典

```
a.copy()
```

- 随机返回字典某一键值对

```
a.item()
```

- 返回某一元素对应的值

```
a.get('x')   # x为改元素的键
```

- 返回所有元素对应的值

```
a.values()
```

- 返回所有元素对应的键

```
a.keys()
```

- 随机返回并删除该键值对

```
a.popitem()
```

**注_意：键值对的键是唯一的，不能出现两个相同的键，值是可变的_**

## 十一.函数

### 1.**格式：**

```
    def 变量名(参数一,参数二):
        (表达式一)
```

****_注意：在Python中可以有返回值，也可以不有返回值，还可以只有 return_****

### 2.**函数的调用**

```
def count(a,b):    #定义函数count，参数为a，b
   return a+b    #返回a+b的值

m = count(1,2)   #此处进行了函数的调用
print(m)

>>3
```

         表达式1

      def 变量名3(self):    #实列方法

```

```
  a = 变量名1(参数一,参数二...)
