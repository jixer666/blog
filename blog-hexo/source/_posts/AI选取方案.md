## 技术方案

- 方案一：直接调用 DeepsSeek 官方或者 OpenAi 提供的 API 接口

- 方案二：本地部署

## 方案一

优点：简单能直接上手、成本低

缺点：数据传输不安全

### DeepSeek API

官方文档：https://api-docs.deepseek.com/zh-cn/

**调用收费规则**

Token 是模型用来表示自然语言文本的的最小单位，可以是一个词、一个数字或一个标点符号等，将根据模型输入和输出（包括提问和 AI 回答）的总 token 数进行计量计费

一般情况下模型中 token 和字数的换算比例大致如下：

- 1 个英文字符 ≈ 0.3 个 token
- 1 个中文字符 ≈ 0.6 个 token

DeepSeek 提供的两种模型对比

![image-20250630164042925](https://gitee.com/lijunxi666/picture-bed/raw/master/customer-service/image-20250630164042925.png)

- Json Output：支持 Json 格式输出
- Function Calling：让模型能够调用外部工具，来增强自身能力
- 对话前缀续写（Beta）：用户可以提供 assistant 开头的消息，来让模型补全其余的消息
- FIM 补全（Beta）：用户可以提供前缀和后缀（可选），模型来补全中间的内容

**扣减费用 = token 消耗量 × 模型单价**

**1. DeepSeek-R1-1.5B**

| CPU     | 内存 | 硬盘                    | 显卡   |
| ------- | ---- | ----------------------- | ------ |
| 最低4核 | 8GB+ | 3GB+（模型大小1.5-2GB） | 非必需 |
