### Bingbong的数数世界

思维题，需要我们找出最终的胜利者

只要这个数是奇数并且这个数除以2的结果也是偶数的话就是`Bing`，否则就是`Bong`

```c++
#include<bits/stdc++.h>
#define endl "\n"
using namespace std;
typedef long long ll;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b, x, y, res;

int main(){
	ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
	cin >> a;
	while(a --){
		cin >> b;
		if(b / 2 % 2 == 1 || b % 2 == 1){
			cout << "Bing" << endl;
		} else {
			cout << "Bong" << endl;
		}
	}
	
	return 0;
}
```

### Bingbong的蛋仔世界

这题一看到需要向四个方位移动，我立马就想到了DFS，可是仔细读题后发现后并不需要。

只需要判断某个点是否能在边界消失完到达中心点即可；该点到中心点的距离 = 横坐标之差 + 纵坐标之差

```c++
#include<bits/stdc++.h>
#define endl "\n"
using namespace std;
typedef long long ll;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b, x, y, res;

int main(){
	ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
	cin >> a >> b >> x;
	int midx = a / 2, midy = b / 2;
	int mcot = max(midx, midy);
	while(x --){
		int n1, n2;
		cin >> n1 >> n2;
		n1 --, n2 --;
		int cot = fabs(n1 - midx) + fabs(n2 - midy);
		if(cot <= mcot) res ++;
	}
	cout << res << endl;
	
	return 0;
}
```

### Bingbong的奇偶世界

~~每次到差不多第三，四个题的位置总是会卡~~，这题我赛时的思路和题解的思路大差不差，估计某处细节没考虑不到导致一直卡。

思路：比如当前点为`i`，那么这点之前的所有满足条件的个数有`pow(i - 1, 2) + 1 - 含有前导0的数` ，每次循环遍历的时候都需要判断是否是0、奇数、偶数。并且在每次循环的时候就需要维护`pow`和`前导0的数`这两个值，不能直接通过`pow`来计算因为会超时，我感觉我g应该就出在这里。

我的代码

```c++
#include<bits/stdc++.h>
#define endl "\n"
using namespace std;
typedef long long ll;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b, x, y, res;
int mod = 1e9 + 7;
ll n[N];

int main(){
	ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
	cin >> a;
	ll cot = 1, cc = 1;
	char c;
	for(int i = 1; i <= a; i++){
		cin >> c;
		if((c - '0') % 2 == 0){
			n[i] = (n[i - 1] + cc + 1 - cot) % mod;
			if(c == '0'){
				cot = cot * 2 % mod;
			}
		} else {
			n[i] = n[i - 1];
		}
		cc = cc * 2 % mod;
	}

	cout << n[a] << endl; 
	return 0;
}
```

正解

思路是每次循环的时候就去掉了0的前导数的值，当不是0的时候就直接相加，不需要想我的思路那样单独来减，容易出错。

```c++
#include<bits/stdc++.h>
#define endl "\n"
using namespace std;
typedef long long ll;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b, x, y, res;
int mod = 1e9 + 7;
ll n[N];

int main(){
	ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
	cin >> a;
	ll cot = 0, cc = 0;
	char c;
	for(int i = 1; i <= a; i++){
		cin >> c;
		if(c == '0'){
			cot = (cot + cc + 1) % mod;
			cc = cc * 2 % mod; 
		} else if((c - '0') % 2 == 0){
			cot = (cot + cc + 1) % mod;;
			cc = (cc * 2 + 1) % mod; 
		} else {
			cc = (cc * 2 + 1) % mod;
		}

	}

	cout << cot << endl; 
	return 0;
}
```
