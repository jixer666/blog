## 咕呱蛙

这题就是看思维了，从前几个满足条件的数中找出规律，只有 4i + 2 和 4i + 3的数满足条件，于是考虑这两个数出现位置

对于 4i + 2，直接就是 2n，对于4i + 3，也是很快知道为 2n + 1

```c++
#include<bits/stdc++.h>
#define line printf("------\n")
```

## 得分显示

这题题意很简单，但是很难想到一点就是，因为是递增的，所以后面出现的数x对于前面出现n个数满足，每次增加都不能超过x/n。 

```c++
#include<bits/stdc++.h>
#define line printf("------\n")
#define endl "\n"
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b;

int main(){
	ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
  	cin >> a;
  	int num;
  	double res = 1e9 + 1;
  	for(int i = 1; i <= a; i++){
  		cin >> num;	
  		res = min(res, (num + 0.9999999999999) / i);
	}
	printf("%.10lf", res);
}
```

## 阿里马马与四十大盗

这题用了贪心的思想，对于某个0补充到最大值后，若后面的数之和都小于这个最大值，则后面的0就不用管了无需补充；于是这个某个0之前的0都需要补充到最大值

```c++
#include<bits/stdc++.h>
#define endl "\n"
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> PII;
const int N = 1e6 + 10, M = 1e9 + 10;
int ix[4] = {1,-1,0,0}, iy[4] = {0,0,1,-1};
int a, b;
int v[N];
ll m[N];
ll fun(int x){
	return m[a] - m[x];
}

int main(){
    ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
	cin >> a >> b;
	ll res = 0, is = 0, cot = b, flag = 0;
	for(int i = 1; i <= a; i ++){
		cin >> v[i]; 	
	}
	for(int i = 1; i <= a; i++){
		m[i] = m[i - 1] + v[i];
	}
	for(int i = 1; i <= a - 1; i ++){ 
		if(v[i] == 0){
			res += b - cot;
			cot = b; 	
			if(cot > fun(i)){
				cout << res + a - 1 << endl;
				return 0;
			}
		} else {
			cot -= v[i];
			if(cot <= 0){
				cout << "NO" << endl;
				return 0;
			}
		}		
	}

	cout << res + a - 1 << endl;
	
    return 0;
}
```
