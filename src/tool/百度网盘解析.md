# 百度网盘解析

## 接口文档

### 提取分享文件

【POST】https://pan.baidu.com/share/verify

请求参数

```
surl=4eS6087W-_siGRLp_1EeIA
```

返回结果

```json
{
    "errno": 0,
    "err_msg": "",
    "request_id": xxx,
    "randsk": "xxxx"
}
```

会将 `BDCLND` 和 `PANPSC` 设置到 Cookie 中

### 获取分享文件列表

【GET】https://pan.baidu.com/share/list

请求参数

```
page=1&num=20&order=time&shorturl=YQGvmKh0DaOMA39KDc3fcQ&root=1
```

Cookie

```
BDCLND=xxx;
```

返回结果

## 实现原理

用户输入分享链接，系统调用获取分享文件接口，列出分享的文件，由用户自己选择下载一个或者多个文件，系统将这些文件保存在自己的一个 SVIP 账号里，由 SVIP 账号获取不限速的下载链接地址
