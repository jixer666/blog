# 百度网盘解析

## 接口文档

### 提取分享文件

【POST】https://pan.baidu.com/share/verify

请求参数

```
surl=4eS6087W-_siGRLp_1EeIA
```

表单参数

| Key  | Value |
| ---- | ----- |
| pwd  | xxxxx |

返回结果

```json
{
    "errno": 0,
    "err_msg": "",
    "request_id": xxx,
    "randsk": "xxxx"
}
```

会将 `BDCLND` 和 `PANPSC` 设置到 Cookie 中

### 获取分享文件的下载地址

【POST】https://pan.baidu.com/api/sharedownload

请求参数
```
https://pan.baidu.com/api/sharedownload?sign=a25723edb9faae6ae7e81c039293317678c7426a&timestamp=1752064660&channel=chunlei&web=1&app_id=250528&bdstoken=50696cec2249f2fdbd9879bf7bbc74bb&clienttype=0
```

表单数据

| Key       | Value             |
| --------- | ----------------- |
| encrypt   | 0                 |
| extra     | {"sekey": "xxxx"} |
| product   | share             |
| uk        | xxxx              |
| primaryid | xxxx              |
| fid_list  | [xxxx]            |

- extra：获取 Cookie 中的 BDCLND 参数或 Localstorage 中的 xxxx_bdclnd 参数（xxx 是分享链接中的 s 后面的部分）

  贴上从 `download-all.js` 中查找 extra 参数的代码

## 实现原理

用户输入分享链接，系统调用获取分享文件接口，列出分享的文件，由用户自己选择下载一个或者多个文件，系统将这些文件保存在自己的一个 SVIP 账号里，由 SVIP 账号获取不限速的下载链接地址
