## Nginx 搭建

访问链路：Nginx -> 网关 -> 具体服务

### Host 配置

打开文件 `‪C:\Windows\System32\drivers\etc\hosts`，添加下行文字，保存并覆盖（需要用管理员权限）

```
127.0.0.1 gulimall.com
```

原理：浏览器在访问 `gulimall.com` 这个网站的时候，会先从本机中的 Host 文件去查找是否存在，否存在就返回对应设置的 IP 地址；若不存在就去解析  `gulimall.com` 去获取真实的 IP 地址

### Nginx 配置

作用：方向代理 + 负载均衡

注意：必须要添加 `proxy_set_header Host $host` ，否则在 `Nginx`  反向代理到网关是没有 `Host` 这个参数的，网关就匹配不到出现404错误

```nginx
http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    upstream gulimall {
        server 127.0.0.1:88;
    }

    server {
        listen       80;
        server_name  gulimall.com;

        location / {
            proxy_pass http://gulimall;
            proxy_set_header Host $host;
        }

        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   html;
        }
    }

}

```

### 网关配置

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: gulimall_host_route
          uri: lb://gulimall-product
          predicates:
            - Host=**.gulimall.com,gulimall.com # 根据 Host 进行断言
```
