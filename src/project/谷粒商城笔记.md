## Nginx 搭建

访问链路：Nginx -> 网关 -> 具体服务

### Host 配置

打开文件 `‪C:\Windows\System32\drivers\etc\hosts`，添加下行文字，保存并覆盖（需要用管理员权限）

```
127.0.0.1 gulimall.com
```

原理：浏览器在访问 `gulimall.com` 这个网站的时候，会先从本机中的 Host 文件去查找是否存在，否存在就返回对应设置的 IP 地址；若不存在就去解析  `gulimall.com` 去获取真实的 IP 地址

### Nginx 配置

作用：方向代理 + 负载均衡

注意：必须要添加 `proxy_set_header Host $host` ，否则在 `Nginx`  反向代理到网关是没有 `Host` 这个参数的，网关就匹配不到出现404错误

```nginx
http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    upstream gulimall {
        server 127.0.0.1:88;
    }

    server {
        listen       80;
        server_name  gulimall.com;

        location / {
            proxy_pass http://gulimall;
            proxy_set_header Host $host;
        }

        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   html;
        }
    }

}

```

### 压力测试

**常用的性能指标**

- HPS：每秒点击次数

- TPS：系统每秒处理交易数

- QPS：系统每秒处理查询次数

  对于互联网业务中，如果某些业务有且仅有一个请求连接，那么TPS = QPS = HPS，一 般情况下用 TPS 来衡量整个业务流程，用 QPS 来衡量接口查询次数，用 HPS 来表 示对服务器单击请求

- 吞吐量：每秒钟系统能够处理的请求数、任务数

- 响应时间：服务处理一个请求或一个任务的耗时

- 错误率：一批请求中结果出错的请求所占比例

**Jmeter 地址问题**

Jmeter 持续使用一段时间后会报错

```java
java.net.BindException: Address already in use: connect
```

解决办法：

- cmd 中用 `regedit` 命令打开注册表
- 在 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters` 下：
  - 右击 `parameters`，添加一个新的 `DWORD`，名字为 `MaxUserPort`
  - 然后双击 `MaxUserPort`，输入数值数据为65534，基数选择十进制
